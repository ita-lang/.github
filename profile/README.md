# Itá Programming Language 🪨

**Itá** (pedra em Tupi antigo) — linguagem de programação imutável por default, funcional-first, fortemente tipada.

## Repos

| Repo | Description |
|------|-------------|
| [`ita`](https://github.com/ita-lang/ita) | Compiler + language |
| [`stdlib`](https://github.com/ita-lang/stdlib) | Standard library |
| [`vscode-ita`](https://github.com/ita-lang/vscode-ita) | VS Code extension |
| [`tree-sitter-ita`](https://github.com/ita-lang/tree-sitter-ita) | Tree-sitter grammar |

## Philosophy

1. Immutable by default
2. Value vs Reference — explicit
3. No magic — never hides what happens
4. Functional-first, OO when it makes sense
5. Zero annotations, zero try/catch
